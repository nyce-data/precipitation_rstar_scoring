# PERSIANN-CDR Daily: threats to its inputs, January 2024 to November 2026 (Part 5)

**Short answer.** No input has been terminated in a way that stops PERSIANN-CDR Daily. Several are in the middle of changes or losses, though, and two are emerging risks to its extension. Overall confidence: moderate.

The two emerging risks:
- **GPCP v2.3 monthly** is still extended, but NCEI has marked it "Version Superseded" by GPCP V3.3 (2025-08-05) and gives no retirement date. PERSIANN-CDR still uses v2.3 for each new month.
- **GridSat-B1** lost its calibration source when HIRS data ended in 2024. It has switched to VIIRS, and the same recalibration has paused GPCP V3.3.

The microwave and sounder losses behind GPCP (DMSP SSMIS, NOAA POES, eventually Aqua AIRS) are imminent or already happening. They act on PERSIANN-CDR only through GPCP's monthly bias adjustment, so they would degrade it rather than stop it. Stage IV radar matters little: it was used only to train the model. Neither CHRS nor NCEI has announced a substitute input for PERSIANN-CDR.

## What the dataset depends on

PERSIANN-CDR Daily is a derived product. For each month it needs two inputs:
- **GridSat-B1 IR**, the primary input, itself a CDR;
- **GPCP monthly**, used for bias adjustment ([C-ATBD, 2014](https://www.ncei.noaa.gov/pub/data/sds/cdr/CDRs/PERSIANN/AlgorithmDescription_01B-16.pdf); [NCICS Obs4MIPs note, 2016](https://ncics.org/ncics/pdfs/obs4MIPs/Obs4MIPs%20PERSIANN-CDR%20Technical%20Note%20v0-3.pdf)).

NCEP Stage IV was used only to pretrain the neural network; "the parameters of the model are kept fixed" after that ([Ashouri et al., 2015](https://www.atmos.albany.edu/daes/atmclasses/atm305/2015/pdf/Ashouri_et_al_2015_BAMS.pdf)). The User Guide ties each extension to both monthly inputs: it is extended "as new GridSat-B1 IR data and GPCP monthly rainfall data become available" ([User Guide, Dec 2025](https://www.ncei.noaa.gov/pub/data/sds/cdr/CDRs/PERSIANN/UserGuide_01B-16.pdf)). No document names a fallback input.

The file headers show the GPCP version actually used. The file for 2026-07-30 lists `gpcpv23_m2607.bin`, so the latest months use **GPCP v2.3**, although the User Guide still says v2.2 ([NCEI PERSIANN-CDR attributes, 2026](https://www.ncei.noaa.gov/thredds/dodsC/ncFC/cdr/persiann-fc/PERSIANN:_aggregation_best.ncd)). High confidence.

## Key findings

**1. The GPCP version is the main emerging risk (moderate confidence).** PERSIANN-CDR's bias adjustment still uses GPCP v2.3. That product is still produced: NCEI's folder holds final months to August 2026 and preliminary months for September and October ([NCEI, 2026](https://www.ncei.noaa.gov/data/global-precipitation-climatology-project-gpcp-monthly/access/2026/)). But NCEI's record for V3.3 calls v2.3 "Version Superseded" and says users should not use it except in rare cases ([NCEI via data.gov, 2025](https://catalog.data.gov/dataset/noaa-climate-data-record-cdr-of-the-global-precipitation-climatology-project-gpcp-monthly-)). The GPCP team says V4 is "targeting mid 2027" ([Behrangi et al., 2026](https://ipwg12.imgw.pl/wp-content/uploads/2026/07/S3.4-BEHRANGI-IPWG2026.pdf)). UMD's interim v2.3 summaries still run to October 2026 ([UMD ESSIC, 2026](https://essic.umd.edu/globalprecipitation/)). No date to freeze v2.3 was found, and no plan for PERSIANN-CDR to move to V3.3 or V4. A switch would not be simple: V3.3 itself takes PERSIANN data as an input (raw PERSIANN-CDR, per the GPCP team).

**2. GridSat-B1's calibration changed underneath it (high confidence on the event).** The GridSat-B1 C-ATBD Rev 2 says HIRS all-sky data production "ceased in 2024". It now intercalibrates the geostationary IR against VIIRS VGAC, with a constant adjustment for continuity with the HIRS record of 1980–2024 ([Knapp, 2026](https://www.ncei.noaa.gov/pub/data/sds/cdr/CDRs/Geostationary_IR_Channel_Brightness_Temperature/AlgorithmDescription_01B-02.pdf)). GPCP V3.3 production was paused "while NCEI is developing a new calibration procedure for the GridSat IR input product due to the retirement of the previous calibration source" ([GPCP V3.3 release notes, 2025](https://docserver.gesdisc.eosdis.nasa.gov/public/project/MEaSUREs/GPCP/Release_Notes.GPCPV3.3.pdf)). GridSat-B1 kept being extended to October 2026, so the change hasn't stopped PERSIANN-CDR. No source says whether PERSIANN-CDR's months from 2024 on use GridSat data calibrated the new way.

**3. Satellite changes behind GridSat-B1 were absorbed (high confidence).** The GridSat-B1 file headers show GOES-19 replacing GOES-16, Himawari-8 filling in during Himawari-9's outage, and Meteosat-11 covering for Meteosat-10. The October 2026 files list "GOES-18,GOES-19,Himawari 9,Meteosat-9,Meteosat-10" ([NCEI header, Oct 2026](https://www.ncei.noaa.gov/thredds/dodsC/cdr/gridsat/2026/GRIDSAT-B1.2026.10.01.12.v02r01.nc.das)). The open question is Europe and the Indian Ocean. GridSat-B1 still relies on the ageing MSG satellites and has not taken in MTG (Meteosat-12), and NCEI's ISCCP B1 table is out of date ([NCEI ISCCP B1 page](https://www.ncei.noaa.gov/products/satellite/international-satellite-cloud-climatology-b1)).

**4. Microwave and sounder losses act through GPCP (moderate confidence).** DMSP SSMIS was due to end in July 2025, then was extended to September 2026 ([NASA Earthdata, 2025](https://www.earthdata.nasa.gov/data/alerts-outages/status-update-dmsp-data-products)). NOAA's archive (CLASS) reported "DMSP data flow stopped on 9/30/2026", and the provider then resumed sending backlog and new data ([NOAA CLASS, 2026-10-23](https://www.aev.class.noaa.gov/)). The Space Force says it will operate DMSP until the satellites fail, "no earlier than 2028" ([Air & Space Forces, 2026](https://airandspaceforces.com/space-force-legacy-weather-sats-2028-replacements); one trade-press source). NOAA's POES data ended in June 2025 ([NOAA CLASS](https://www.aev.class.noaa.gov/)). NASA projects the end of Aqua's science mission for September 2027 ([NASA, 2025](https://science.nasa.gov/science-research/earth-science/terra-the-end-of-an-era/)). No dated GPCP plan to replace SSMIS was found. The nearest is a GPCP team member's 2023 slides naming WSF-M, whose data NOAA began distributing in July 2026 ([NOAA OSPO, 2026](https://ospo.noaa.gov/data/messages/2026/07/MSG_20260720_1313.html)).

**5. Stage IV, GPCC and NCEI pose little threat (moderate confidence).** Stage IV is still posted daily, and no NWS notice names it ([NWS](https://api.water.noaa.gov/resources/downloads/precip/stageIV/2026/11/)). It is used only for training anyway. GPCC is restructuring its products but still extends the Monitoring Product ([DWD](https://opendata.dwd.de/climate_environment/GPCC/monitoring_v2022/2026/)). NCEI says "No datasets will be retired as part of the cloud migration", but warns of slower updates ([NCEI FAQ, 2026](https://www.ncei.noaa.gov/news/cloud-migration-FAQ)).

## Conflicting evidence

- **GPCP version:** the User Guide (Dec 2025) says v2.2; the 2026 file headers name v2.3 files. This answer relies on the headers, as the record of what was actually used.
- **When GPCP V3.3 was paused:** March 2024 in the V3.3 release notes ([Huffman et al., 2025](https://docserver.gesdisc.eosdis.nasa.gov/public/project/MEaSUREs/GPCP/Release_Notes.GPCPV3.3.pdf)). September 2024 on [NASA Earthdata](https://www.earthdata.nasa.gov/data/catalog/ges-disc-gpcpmon-3.3) and in the Copernicus Climate Data Store's forum post of 2 Dec 2025. The later sources and the checker's search favour September 2024. The GPCP team's July 2026 talk lists V3.3 to December 2025, and the CDS post's October 2026 update mentions extensions into 2025, so the pause has since partly lifted. Unresolved.
- **Aqua's end date:** a 2023 Aqua status deck projected the instruments shut down on 26 Aug 2026; NASA's December 2025 note moves the end of science to September 2027. AIRS was still running in late October 2026, so this answer uses the later date.
- **DMSP F16:** WMO OSCAR lists it as Inactive, while NOAA OSPO's September 2026 notice still lists new file names for F-16 SSMIS. OSCAR's records lag; unresolved.

## Gaps

- No CHRS or NCEI statement on moving PERSIANN-CDR off GPCP v2.3, or on what happens if v2.3 is frozen. CHRS (chrs.web.uci.edu) and NCEI's CDR Program could say; ask them.
- No date for GPCP v2.3's retirement. NCEI and UMD ESSIC (the GPCP v2.3 producer) hold it; watch the GPCP v2.3 landing page, which returned HTTP 502/503 during NCEI's cloud migration.
- Which DMSP satellites still deliver after 30 Sep 2026, and whether GPCP's Sep–Oct 2026 preliminary months used SSMIS: neither was found. OSPO's message archive and the GPCP file metadata would show it.
- Whether PERSIANN-CDR's 2024–2026 months use the VGAC-recalibrated GridSat-B1: not stated in the PERSIANN-CDR documents.
- Copies elsewhere lag: a search summary (not read) says Google Earth Engine's GridSat-B1 copy has not been updated since 2024. That copy is not NCEI's archive, which PERSIANN-CDR's files name.
- No source on when MTG enters ISCCP B1. EUMETSAT and NCEI (the ISCCP B1 table) hold it. EUMETSAT's own pages returned 403 to the run's tools.
