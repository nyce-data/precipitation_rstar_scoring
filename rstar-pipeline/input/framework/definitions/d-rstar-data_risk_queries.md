# D: Data Risk

## Data Risk defined

Probability of loss through technical failure, policy disruption, or infrastructure degradation. Includes storage system vulnerabilities, format obsolescence, access infrastructure dependencies, and the direct effects of program terminations or defunding. Weighted most heavily because it is the most direct signal of imminent loss.

D covers the dataset as a product and the places that serve it: the programs that produce and host it, where it is stored and how users reach it (including the repository going offline), its formats, and political pressure on it. Because the dataset is served by its repository, repository facts count in D-2 and D-3 as well as in RRS.

## Subcategories

### D-1

#### Description

Active or threatened program termination/defunding

The program producing or hosting this dataset has been cut, is under active budget threat, or has lost its legislative mandate

#### How to find

Search for the group(s) or program(s) that produces the dataset and look for funding threats and cuts from 2025-present. And do the same for the program that is in charge of hosting and serving the dataset.

#### What counts as evidence

Funding cuts, budget threats or a lost mandate, from 2025 to the present, for the program that produces the dataset and for the program that hosts and serves it.

### D-2

#### Description

Storage system end-of-life or single point of failure

Data resides on infrastructure that is aging out, unsupported, or has no failover — a single system going down means data goes offline.

#### How to find

Want to know if the dataset is in danger of not being accessible and served in the near future. Search for how the data is stored and served (group computers, the cloud, data repository). Is the dataset only served from one organization. Include all information related to infrastructure around the dataset.

#### What counts as evidence

How and where the data are stored and served (the producer's own computers, the cloud or a data repository), whether only one organization serves them, and any sign that the storage is aging, unsupported or has no backup system to take over.

### D-3

#### Description

Access infrastructure fragile or unfunded

The portal, API, or distribution system serving users is grant-funded, maintained by a single developer, or at risk of going dark

#### How to find

Search for the dataset endpoints (data repositories, hosting platforms, group website) and determine the funding and staffing of them. Search if there are any threats to the funding or staff cuts or layoffs. Want to know if the dataset will be available uninterrupted in the near future. Have there been interruptions in the past that suggest it could happen again.

#### What counts as evidence

Who funds and staffs the places users get the data from (data repositories, hosting platforms, the producer's website), any threatened cuts or layoffs there, and past outages that suggest access could be interrupted again.

### D-4

#### Description

Format obsolescence

Data stored in proprietary or legacy formats whose reader tools are unmaintained or vendor-dependent

#### How to find

Search for all the formats that data is served in and check if they are in a FAIR format. Is proprietary software need to process the data or use the data?

#### What counts as evidence

The file formats the data come in, whether they are open and widely supported (in line with the FAIR principles), and whether reading or using the data needs proprietary or unmaintained software.

### D-5

#### Description

Political sensitivity

Dataset subject to active suppression, alteration pressure, or interference that could result in records being removed, modified, or access-restricted for non-scientific reasons

#### How to find

Search for political threats to the dataset funding and staffing. If a dataset is in the news for funding cuts or termination, it's important information to know if the dataset will continue to be accessible in the near future.

#### What counts as evidence

News of political pressure on the dataset: funding or staff cuts, threatened termination, or pressure to remove, change or restrict the records for reasons other than science.
